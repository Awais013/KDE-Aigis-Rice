## Components

### Desktop Environment
* **Distro:** KDE Plasma
* **Global Theme:** GruvboxPlasma
* **Plasma Style:** Utterly-Round
* **Terminal:** [Ghostty](https://ghostty.org/) (with blurred transparency)
* **Shell:** Bash (custom PS1 with Sage/Brass accents)
* **Launcher:** Rofi

### Terminal HUD
* **Fetch:** [Fastfetch](https://github.com/fastfetch-cli/fastfetch) 
    * *Customized with P3 Menu borders and Aigis banner.*
* **Visualizer:** [CAVA](https://github.com/karlstav/cava)
    * *Sage-to-Brass gradient frequency analyzer.*
* **Monitor:** [Btop](https://github.com/aristocratos/btop)
    * *Aigis-themed mechanical diagnostics skin.*
* **File Manager:** [Ranger](https://github.com/ranger/ranger)
    * *Custom Python colorscheme with Devicons.*
